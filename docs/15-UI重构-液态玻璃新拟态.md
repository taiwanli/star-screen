## 液态玻璃 + 新拟态 · 浅色模式

> 日期：2026-09-27 ｜ 范围：三端壳 / 源管理 / 播放控制 / 海报卡

---

## 1. 现状摘要

| 层 | 现状 |
|----|------|
| 默认主题 | 暗色影视风（docs/07 D1） |
| 色彩 | 中性 950–50 阶梯 + 品牌蓝 `#1F6FB4` |
| 形态 | 扁平卡片、1px 描边、大圆角（TV 更大） |
| 组件 | StarPoster / 字幕面板 / 导入向导 / LAN 面板 |
| 问题 | 亮色仅换底色，缺少玻璃层次与质感；组件阴影弱、层次平 |

## 2. 新风格定义

### 2.1 液态玻璃（Liquid Glass）
- **磨砂层**：`BackdropFilter blur 18–28` + 半透明白底 `rgba(255,255,255,0.55–0.72)`
- **描边高光**：1px `rgba(255,255,255,0.65)` 内描边
- **分层**：页面底 → 玻璃面板 → 内容；避免多层嵌套模糊（性能）
- **圆角**：`radius.lg = 20`（卡片）/ `xl = 28`（浮层）

### 2.2 新拟态（Neumorphism）
- **浅灰底** `#E8EEF5`（主背景）
- **双向阴影**：左上亮 `rgba(255,255,255,0.9)` / 右下暗 `rgba(163,177,198,0.55)`
- **按钮按下**：阴影反转（inset）
- **只用于**：主要按钮、导航胶囊、滑块轨道 — 不整页堆砌

### 2.3 浅色模式色板
| Token | 值 | 用途 |
|-------|-----|------|
| page | `#E8EEF5` | 页面底 |
| glass | `rgba(255,255,255,0.62)` | 玻璃面板 |
| surface | `#F4F7FB` | 列表/卡片底 |
| ink | `#152033` | 主文字 |
| brand | `#2F7FD1` | 主操作（锁死蓝系） |
| neuLight | `#FFFFFF` | 新拟态亮阴影 |
| neuDark | `#A8B7C8` | 新拟态暗阴影 |

| 组件 | 新处理 |

## 4. 实施步骤（本轮）
1. `StarGlass` / `NeuBox` 组件与 token

4. 海报卡与主按钮质感升级  

## 5. 约束
- TV 保持高对比（玻璃透明度更低、阴影更重）
- 品牌蓝与语义色锁定，不随主题变相
- 模糊仅用于浮层/顶栏，列表用半透明底避免卡顿
