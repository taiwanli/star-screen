## 1. 总览

```text
用户输入（URL / 文件 / 文件夹 / 粘贴 / 深链）
        │
        ▼
┌──────────────────┐
│  FeedFetcher     │  http + ETag / LocalFeedPolicy
└────────┬─────────┘
         ▼
┌──────────────────┐     starrule:// → inline/url
│  导入识别         │─────────────────────────┐
└────────┬─────────┘                         │
         ▼                                   ▼
  StarRuleParser                    TvBoxConfigParser
         │                                   │
         │                          xpath → XpathToStarRule
         │                          drpy  → DrpyToStarRule
         ▼                                   ▼
┌─────────────────────────────────────────────┐
│  StarRuleImporter / ParseReport             │
│  → SourceDef[]（kind + caps + 参数固化）      │
└────────────────────┬────────────────────────┘
                     ▼
              SourceRegistry（持久化）
                     ▼
         sourceFor(def) → VideoSource
                     │
     ┌───────────────┼───────────────┐
     ▼               ▼               ▼
 CmsJson/Xml   StarRuleSource   DrpyTemplate
     │               │               │
     └───────────────┴───────────────┘
                     ▼
            PlaybackSession → PlayerFacade
              (libmpv / Exo / 外部)
```

**架构红线**：`star_domain` 纯 Dart、零 Flutter；`star_plugins` 可依赖 html；`star_player` 实现内核；三端 app 只做装配与 UI。

## 3. 数据模型

### 3.1 SourceKind（解析器种类）

| 枚举 | 含义 | 三端适配器 |
|---|---|---|
| `cmsJson` / `cmsXml` | 苹果 CMS | CmsJsonSource / CmsXmlSource |
| `xpathRule` | csp_XPath*（导入时可转 StarRule） | 转译后 starRule |
| `drpyJs` | drpy 模板/JS | DrpyTemplateSource |
| `starRule` | **StarRule v1 统一规则** | StarRuleSource |
| `alist` | 网盘挂载 | 登记待接 |
| `spiderJar` | jar 蜘蛛 | 仅 Android 桥 |
| `live` | 直播频道组 | LiveParser |
| `unsupported` | 明确不支持（带原因） | 无 |

### 3.2 SourceDef（注册后的固化定义）

关键字段：`key/name/kind/endpoint/extRaw/extUrl/sourceUrl/jarRef/caps/headers/timeoutSec/unsupportedReason/enabled/groupId`。

**解析器固化**：同一 `key` 再次导入 **不覆盖** 已有定义与启停（防「全局 spider 被覆盖」）。

### 3.3 SourceCaps

`searchable / quickSearch / filterable / changeable` —— 聚合搜索与 UI 分流依据。

## 4. 导入管线

### 4.1 入口 `AppServices.importFromRef`

| 输入形态 | 处理 |
|---|---|
| `https://…` | `FeedFetcher` + ETag 304 协商 |
| 本地文件 | `LocalFeedPolicy.readFile` |
| 本地目录 | `LocalFeedPolicy.readDirectory`（≤50） |
| 粘贴 JSON | 直接解析 |
| `starrule://import?url=` / `?inline=` | 深链 |
| TVBox JSON | `TvBoxConfigParser` |
| StarRule / 规则包 | `StarRuleParser.parsePack` |

### 4.2 LocalFeedPolicy

- 路径：去引号、`file://`、缺扩展名补全（`.json` / `.star.json`）
- 编码：UTF-8 / UTF-16 LE·BE BOM（ConfigCleaner）
- 限制：空文件、>8MB、目录误传
- 格式识别：`starRule` / `tvbox` / `jsonUnknown` / `html`
- 目录批量：跳过坏文件并记 `LocalFeedFailure`

### 4.3 TVBox 映射

| TVBox | 内部 |
|---|---|
| type=0/1 + api | cmsXml / cmsJson |
| type=3 + `csp_XPath*` + ext | **自动 XpathToStarRule** |
| type=3 + `csp_AppYsV2` | cmsJson(variant=appys) |
| type=3 + `csp_AList` | alist |
| type=3 + `*.js` | drpyJs |
| type=3 + 其他 csp_ | spiderJar |
| lives[] | LiveGroup → 频道表 |
| parses/rules/ads | 合规：不导入嗅探；ads 进 PlayUrlFilter |

### 4.4 StarRule 导入

`StarRuleParser` → 校验（致命/警告）→ `StarRuleImporter.toSourceDef`：

- `extRaw` 保留规则原文（执行时 `StarRuleSource.fromDef`）
- CMS 模式：协议内建四链路，无 search 块也 `searchable=true`
- 规则包：`pack.name` → `groupId`

### 4.5 转换器

| 转换器 | 输入 | 产出 |
|---|---|---|
| `XpathToStarRule` | csp_XPath ext JSON | StarRule（`convertedFrom: tvbox-xpath`） |
| `DrpyToStarRule` | `var rule = {…}` | StarRule；`js:` 进 `script` |

## 5. 执行适配器

### 5.1 VideoSource 契约

`home() / category() / search() / detail() / resolve()`  
上游只认契约，不感知来源形态。

### 5.2 StarRuleSource（三端统一）

| sourceType | 求值 |
|---|---|
| `html` | PdfhEngine（`&&` 下钻 + Text/@attr + `:eq(n)`） |
| `json` | `json:path.to.field` |
| `cms` | 苹果 CMS：`ac=list/detail`，`$$$` 线路 |
| `xml` | 简化路径（P1 增强） |

**模板占位**：`{host}{cateId}{catePg}{vid}{wd}{playUrl}{lineId}{filter_*}`  
**后处理**：`regex` / `replace($n)` / `default` / `trim`  
**分页**：`hasMore: auto | pageCount | none`  
**详情 workId**：以 `/` 或 `http` 开头直接请求，否则套 `{vid}` 模板

### 5.3 CmsJson / CmsXml

标准 `?ac=list|detail`、`?wd=`、`?ids=`；`vod_play_from $$$` 线路解析。

### 5.4 DrpyTemplateSource

纯模板走 Pdfh；`js:` 走 QuickJS（`DrpyHost` + SandboxLimits）。

## 7. 健康度与测活

### 7.1 HealthMonitor

| 概念 | 说明 |
|---|---|
| 滑动窗口 | 近 20 次成功率 |
| score | 0.5×成功率 + 0.3×延迟 + 0.2×新鲜度 |
| 阶梯熔断 | 连续失败 5 → 冷却 30min；10 → 24h |
| recover | 清 streak/冷却/失败原因 |

### 7.2 SourceChecker（四链路）

`CheckLevel`: `home` / `search`（默认）/ `detailPlay`  
失败码：`timeout/dns/http/empty/parse/needsJar/needsJs/unknown`

聚合搜索 `SearchEngine.skipKeys` 跳过熔断中的源。

## 8. 播放链路

```
Detail → resolve(workId, ep, lineId)
      → PlayCandidate(url, needsParse, headers)
      → PlaybackSession.start
           needsParse → PlayOutcomeBlocked（合规过滤）
           否则 → PlayOutcomePlaying
      → PlayerFacade
           libmpv  → PlayerPage（完整 OSD）
           exo     → MultiEnginePlayerPage
           system  → 外部 mpv/VLC/PotPlayer
```

**换源保进度**：`PlayRecordStore.copyProgressTo`（集数钳制 + 时长缩放）。

**播放内核**（`PlayerEngineType`）：

| 内核 | 实现 | 适用 |
|---|---|---|
| `libmpv` | media_kit | 默认，三端 |
| `exo` | video_player / ExoPlayer | HLS/DASH/冷门封装 |
| `system` | 进程调起 mpv/VLC/PotPlayer | 特殊格式 |

## 9. 直播 Live

- 导入订阅 `lives[]` → `LiveParser`（TXT `#genre#` / M3U `group-title`）→ `DriftLiveChannelStore.replaceAll`
- UI：分组 + 频道列表 + 玻璃顶栏播放
- **清空**：直播页「清空频道」；源管理「清空全部源」会同步 `liveStore.clearAll`

## 12. 安全与合规

1. 不内置内容源；不执行任意 jar（桌面无桥）
2. `needsParse` 默认过滤，不做网页嗅探
3. 备份/局域网：token 校验，敏感路径限制（docs/13）
4. 本地文件导入大小上限 8MB，防异常负载
