# 星映 · 发布打包指南（v1.0）

> 环境要求见 docs/08。本页脚本在具备 Flutter 工具链与各端 SDK 的机器上执行。

## Windows 桌面

```powershell
# 依赖：Visual Studio C++ 桌面开发、Flutter Windows desktop
.\tools\package-windows.ps1
```

产物：`build\windows\x64\runner\Release\`  
可选：用 `makensis` / Inno Setup 做安装包；签名用 `signtool`（需代码证书）。

## Android 手机 / TV

```powershell
# 依赖：Android SDK、JDK 17
.\tools\package-android.ps1 -App mobile   # 或 tv
```

产物：`apps\<app>\build\app\outputs\flutter-apk\app-release.apk`  
TV 建议再打 `android/app/src/main/AndroidManifest.xml` 的 `LEANBACK_LAUNCHER`。

## 版本与更新

1.  bump `pubspec.yaml` 与 CHANGELOG
2.  发布 `version.json`（检查更新用）：

```json
{ "version": "1.0.0", "url": "https://…/download", "notes": "…" }
```

3.  应用内「源管理 → 检查更新」读取该清单

## 崩溃日志

- 路径：`%APPDATA%\StarScreen\logs\crash-yyyyMMdd.log`（桌面）  
  手机/TV：应用支持目录下 `StarScreen/logs/`
- 含 Flutter / Zone 未捕获异常与超 3s 性能标签

## 合规

发布前过一遍 docs/10 D 组红线：无预置内容源、无 jar 执行路径、needsParse 默认过滤。

## 本机打包备忘（2026-09-26）

- 源码路径含中文时：Android 需 `android.overridePathCheck=true`；AOT 仍可能失败 → **拷贝到纯 ASCII 路径**（如 `C:\XingYingBuild`）再 `flutter build`。
- Windows：需设置 `PROGRAMFILES(X86)` 才能检测 VS；`windows/flutter/ephemeral/.plugin_symlinks` 异常时先删再编。
- media_kit 原生 jar 超时：可从另一端 `apps/*/build/media_kit_libs_android_video/v1.1.7/` 复用 jar。
- 产物已放桌面「星映-发行包」。
