> 依据：用户截图问题 + 对标 IINA / YouTube / 哔哩哔哩 / Infuse / PotPlayer  
> 日期：2026-09-28

## 1. 问题清单（截图实锤）

| # | 现象 | 根因 |
|---|---|---|
| 1 | 左上角标题近黑字，黑场几乎不可见 | `_TopBar` 使用 `StarColors.ink`（#152033 深色），叠在视频上；`glass` 渐变过弱 |
| 2 | 双进度条 | 8px 高 Slider + 下方 `PlayerExtrasBar` 胶片条，视觉上像第二根进度；布局堆叠松散 |
| 3 | 海报只剩色块+首字 | `Image.network` 失败/未请求（缺 Referer、相对 URL、证书）落到 `_fallbackChar` |
| 4 | 控件杂乱 | 倍速/音轨/跳过/字幕/投屏/小窗/内核标识挤在两行，无层级、无自动隐藏 |

## 2. 对标结论（怎么做好）

| 要素 | 标杆做法 | 星映 v2 |
|---|---|---|
| 顶栏 | 返回 + 标题 + 次要操作；**白字 + 黑色渐变遮罩** | 同左，标题 16px 白，副标题集数灰白 |
| 进度条 | **单根** seek 条，带缓冲条、悬停预览 | 单 Slider，track 4px，缓冲用 `buffered` 叠加 |
| 底栏主控 | 播放/暂停 · 音量 · 当前/总时长 ·（spacer）· 字幕/投屏/设置/全屏 | 一行图标条，44px 热区 |
| 次要功能 | 收进「更多/设置」菜单，不常驻 | 倍速/音轨/跳过/清晰度 → 菜单 |
| 交互 | 控件自动隐藏（3s），点按/移动唤出；双击全屏；空格播放；←→ 快退快进 | 同左 |
| 可见性 | 遮罩对比度 ≥ 4.5:1 | 一律白色文字 + 0.55–0.9 黑色 scrim |

## 3. 播放全流程

```
详情页点选集
  → resolve 播放地址（needsParse 过滤）
  → 播放页：黑底 + 视频 + 顶栏/底栏（自动隐藏）
  → 进度记忆（≥5% 才记）
  → 片尾 90% 弹「下一集」倒计时
  → 播完自动下一集 / 停止
  → 返回：退出全屏 → pop
```

错误态：加载 spinner → 失败文案 +「换线路 / 重试」。

## 4. 图片加载链路（海报）

1. URL 归一：`//`→`https:`，相对路径 → host 拼接（CMS 已做，StarRule 补）
2. `StarNetworkImage`：UA + Referer + Accept，`loadingBuilder` 占位，`errorBuilder` 可点重试
3. 证书：沿用 `StarHttpOverrides`
4. 磁盘缓存后续接 `cached_network_image`（P1）
