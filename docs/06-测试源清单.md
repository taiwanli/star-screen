> 用户提供的整理页 [yxzhi.com/14218.html](https://www.yxzhi.com/14218.html)（2025-08-13 整理）已逐条实测：**约七成失效**，与用户判断一致；因此另行补充了 GitHub 活跃仓库作为主力测试资产。
> 网络环境：GitHub raw 与境外接口经 iKuuuVPN 本地代理 `127.0.0.1:7890`，国内域名直连；"待复测"项可能受代理出口影响。

## 1. 测试方法

1. **接口测活**：curl 直连（8s 超时）→ 失败走代理重试；HTTP 200 后判类型（单仓 JSON / 多仓 storeHouse / TXT 直播 / M3U / HTML 落地页）。
2. **结构解析**：单仓 JSON 统计顶层字段与 sites 按 type 分布（xml=0 / json=1 / spider=3）。
3. **CMS 字段实测**：`?ac=list` → `?ac=detail&ids=` → `?wd=` 搜索 → `?ac=videolist&at=xml` 四请求逐字段核对（对照 04 §5）。
4. **播放链路**：取 detail 返回的 m3u8 直链做 HEAD 请求验证可达。
