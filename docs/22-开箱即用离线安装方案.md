# 星映 · 新电脑开箱即用（离线安装）解决方案

> 目标：**新电脑解压/安装后即可用**，不另装 JDK / 播放器 / 运行库  
> 范围：Windows 桌面为主；手机/TV 说明差异  
> 日期：2026-09-28

---

## 1. 问题定义

用户拿到新电脑后，若需要自行安装：

| 依赖 | 若不安装会怎样 | 是否影响主流程 |
|---|---|---|
| JDK/Java | **jar 蜘蛛**不可用 | 主流程（CMS/StarRule/直播）**不受影响** |
| VC++ 运行库 | 极老系统可能缺 dll 启动失败 | 可能影响 |
| 系统解码器 | 个别格式播不动 | 可用「外部播放器」兜底 |
| 其它播放器 | 仅「外部播放器」内核需要 | 可选 |

**结论**：要「完全开箱即用」，必须把 **可选能力也打进包**（尤其迷你 JRE + 桥），并保证 **主播放链零外部依赖**。

## 2. 运行时依赖清单（Windows Release 实测）

```
star_desktop.exe
flutter_windows.dll
libmpv-2.dll, libEGL, libGLESv2, vulkan-1, vk_swiftshader
quickjs_c_bridge.dll          # JS/StarRule script
sqlite3.dll
window_manager / media_kit / file_selector … plugin dlls
data/flutter_assets/
```

**已自包含**：Flutter 运行时、libmpv、QuickJS、SQLite、file_selector。  
**需补进包**：

| 项 | 体积 | 用途 |
|---|---|---|
| `jre-min/`（jlink） | ~44 MB | jar 蜘蛛 |
| `bridge/star-spider-bridge.jar` | ~7 KB | JVM 桥 |
| （可选）VC++ 2015–2022 x64 | ~15 MB | 极老系统兜底 |

## 3. 方案选型

| 方案 | 开箱体验 | 体积 | 评价 |
|---|---|---|---|
| A. 仅 exe，要求用户装 Java | ❌ | 小 | 现状，不符合目标 |
| B. **捆绑 jlink 迷你 JRE** | ✅ | +44 MB | **推荐**，离线、可复现 |
| C. 首次启动在线下 JRE | ⚠ 需网络 | 小 | 不适合无网新机 |
| D. jpackage 打安装器 | ✅ | +JRE | 正式安装体验好，可后续做 |
| E. 不支持 jar，只留 StarRule | ✅ | 最小 | 功能残缺 |
| F. 嵌入完整 JDK | ✅ | +200 MB | 过重 |

**选定：B + D**  
日常 **zip 免安装** 用 B；要「安装程序」用 D（Inno Setup / jpackage）。


**查找顺序（代码已实现）**：

1. `StarScreen/jre-min/bin/java.exe`（捆绑）
2. 开发态 `tools/jre-min/bin/java.exe`
3. 系统 JDK / PATH（兜底）

桥 jar：`StarScreen/bridge/star-spider-bridge.jar`。

## 5. 实施步骤

### 5.1 生成迷你 JRE

```bat
jlink --add-modules java.base,java.logging,java.xml,java.naming,^
      java.desktop,java.sql,java.instrument,java.management,^
      java.security.jgss,java.net.http ^
      --strip-debug --no-header-files --no-man-pages --compress=2 ^
      --output tools\jre-min
```

### 5.2 编译 Jar 桥

```bat
cd tools\java-bridge
javac -encoding UTF-8 StarJarBridge.java
jar cf star-spider-bridge.jar StarJarBridge.class
```

### 5.3 打离线包（已脚本化）

```bat
python tools\package_offline_windows.py
```

产物：`dist/星映-Windows-开箱即用-0.1.0-dev.45.zip`

### 5.4 （可选）Inno Setup 安装器

```iss
[Setup]
AppName=星映 StarScreen
DefaultDirName={autopf}\StarScreen
OutputBaseFilename=StarScreen-Setup
Compression=lzma2
SolidCompression=yes

[Files]
Source: "dist\StarScreen-offline\*"; DestDir: "{app}"; Flags: recursesubdirs

[Icons]
Name: "{autoprograms}\星映"; Filename: "{app}\star_desktop.exe"
Name: "{autodesktop}\星映"; Filename: "{app}\star_desktop.exe"
```

再装 VC++ 静默：

```iss
[Run]
Filename: "{tmp}\vc_redist.x64.exe"; Parameters: "/install /quiet /norestart"; \
  StatusMsg: "安装运行库..."; Check: NeedVCRedist
```

## 8. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 杀软误报 exe/dll | 签名（付费证书）或说明加白 |
| jre-min 缺模块导致个别 jar 失败 | 按报错 `jlink` 增模块；或提示装系统 Java |
| VC++ 缺失（Win7/精简版） | 包内附 `vcruntime*.dll` 或安装器静默装 redist |
| 包体积 ~180MB | 可出「精简包」（不含 JRE，jar 不可用） |
| 合规 | 仍不内置内容源；jar 仅加载用户导入的包 |
