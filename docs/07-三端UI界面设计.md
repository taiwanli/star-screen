## 2. 设计令牌（三层结构沿用规范 §8）

组件只引用 `sys-`/`comp-` 层，禁止直引 `ref-` 与硬编码。端差异仅发生在端覆盖文件（`tokens.tv.css` 等）。

### 2.1 颜色（暗色默认 · 三端同值）

| 令牌 | 值 | 来源 |
|---|---|---|
| `sys-color-bg-page` | `#0D1015`（中性 950） | 规范色板 |
| `sys-color-bg-surface` / `-raised` | `#171B21` / `#20262E`（900 / 800） | 规范色板 |
| `sys-color-border` / `-strong` | `#2A3038` / `#3E454F`（800 / 700） | 规范色板 |
| `sys-color-text-primary/secondary/tertiary/disabled` | `#F7F8FA` / `#CBD0D8` / `#9BA3AF` / `#6E7785` | 规范色板 50/300/400/500 |
| `sys-color-bg-brand` | `#1F6FB4`（hover #4B8CCB / pressed #175A93） | **规范品牌 500/400/600 原值** |
| 语义色（成功/警告/错误/信息） | `#1F8A4C` / `#B26A00` / `#C0322B` / `#1F6FB4` | **规范语义主色原值**；浅底色在暗色下转为 12–18% 透明度底 |
| 焦点色 | 桌面 `#4B8CCB` 2px 环 / TV `#4B8CCB` 3px 描边 + 缩放 | 对比度 ≥3:1 |

### 2.2 尺寸与字体（端覆盖）

| 令牌 | 桌面 | 手机 | TV | 
|---|---|---|---|
| `sys-font-size-body` | 14px/1.6 | 16sp/1.5 | 24px/1.5（≥20 底线） |
| `sys-size-control-height-sm/md/lg` | 32/36/40 | 40/48/56 | 72/88 |
| `sys-size-touch-target-min` | 24×24 | 48×48 | 100×100（推荐 160×160） |
| `sys-space-page-margin` | 24px | 16dp | 48px（安全区内布局再缩进 48px） |
| `sys-radius-sm/md/lg/xl` | 4/8/12/16 | 4/8/12/16 | 8/12/18/24（×1.5） |
| `sys-border-width-base/focus` | 1px / 2px 环 | 1dp / — | 1px / **3px** |
| `sys-duration-fast/base/slow` | 120/200/320ms | 同左 | **180/300/480ms（×1.5）** |
| `sys-elevation-1/5` | 0 1px 2px .06 / — | 同左 | 0 2px 8px .30 / 0 12px 40px .55 +缩放 |

其他端级规则：手机 4 列栅格/边距 16dp/左右 20dp 手势禁区无交互；桌面 12 列/最大内容宽 1440/最小窗 1024×640/125–200% 缩放不破；TV 12 列/安全区 48px/字重仅 400–500/无网络字体/无滚动条/长列表虚拟化。

## 3. 信息架构与导航（统一页面集 × 三端导航壳）

页面集（三端一致）：首页 / 点播（分类）/ 直播 / 搜索 / 详情 / 播放 / 我的（收藏·历史·下载）/ 源管理 / 设置。

| 端 | 一级导航 | 层级上限 | 次级承载 |
|---|---|---|---|
| 桌面 | 左侧导航 240px（可折叠 64）：首页/分类/搜索/直播/我的/源管理 + 设置；顶栏 56px 全局搜索（Ctrl+F） | ≤4 | 居中模态、右键菜单 |
| 手机 | 底部标签栏 4 项（80dp）：首页/分类/搜索/我的 | ≤3 | **底部弹层**（清晰度/线路/内核）、Snackbar、下拉刷新 |
| TV | 顶部固定栏目：首页/点播/直播/搜索/我的（+设置）；内容区书架模型 | ≤3 | 居中模态（焦点管理 F1–F8）、OSD |

## 4. 影音模式落地（规范第 6 章 → 星映实现）

### 4.1 内容卡片体系（三端锁死）
- 三形态：海报卡 2:3（电影/剧集：桌面 160×240、手机 112×168）/ 横版卡 16:9（综艺/直播/继续观看：桌面 224×126、手机 168×94、**TV 480×270**）/ 方卡 1:1（P2 预留）。
- 信息层级三级锁死：标题（2 行省略）→ 副信息（`年份 · 地区 · 分类` / 连载改 `更新至第 N 集` / `全 N 集`）→ 角标（≤2 个）。
- 继续观看卡：叠加进度条（桌面 2px / 手机 2dp / **TV 6px**）+ 副信息替换为 `第 N 集 · 剩余 M 分钟`。
- 交互态：桌面悬停=升层级+播放入口+快捷集数；手机按下 0.96/150ms 回弹；TV 默认仅一行标题、**聚焦时放大 1.06 + 3px 描边 + elevation-5 并展开标题与副信息**。

### 4.2 角标语言（星映裁剪版）
沿用规范六类角标的形状/位置/色调逻辑，裁掉「会员」，新增两类星映自有角标（遵循同一语言：左上=来源属性、右上=状态）：

| 角标 | 位置 | 规则 |
|---|---|---|
| 更新至 N 集 / 全 N 集 / 完结 / 直播中 / 预告 | 同规范（右上/左上；直播中红点为全站唯一红色角标） | 三端等比缩放 |
| **多源 N**（星映新增） | 左上、品牌色底白字 | 聚合搜索归并卡专用 |
| **蓝光/4K**（清晰度备注） | 右上、半透明黑底 | 取自 vod_remarks 归一 |

### 4.3 详情页（区块顺序锁死 + 主按钮状态机）
①主视觉（背景剧照虚化）→②标题+评分+元数据（≤2 行）→③**主操作区**→④选集→⑤简介（默认 3 行）→⑥演职→⑦相关推荐。
- 布局：桌面左 40/右 60；手机单列 + **主操作吸底**；TV 左 35/右 65，**一屏同见「播放」与「选集」**。
- 主按钮状态机（三端同文案）：未播=「立即播放」；看过=「继续观看 · 第 N 集 12:35」；看完（影）=「重新播放」；看完（剧）=「继续观看 · 第 N 集」。
- 星映特有次级操作排：收藏 / 下载 / 分享 / **换源 (N)**（跨源切换，线路切换在播放器内）。

### 4.4 播放器（画面层一致，控制层按端重做）
| 能力 | 桌面 | 手机 | TV |
|---|---|---|---|
| 唤起/隐藏 | 鼠标移动显隐，静止 3s 淡出 | 单击显隐（**单击不暂停**），4s | 任意键唤起，5s（拖动中不隐藏） |
| 进度 | 4px→悬停 8px+关键帧预览+时间戳 | 视觉 3–4dp，**热区 ≥44dp，两端内缩 ≥24dp** | 6px，**默认焦点在进度条**，显示当前/总时长/**剩余时间 ≥24px** |
| 手势 | — | 双击左右 ±10s、横拖进度、左半屏亮度/右半屏音量、长按倍速（角标 2.0×） | ←→ 短按 10s/长按连续 |
| 键盘基线 | Space/←→/↑↓/Shift+←→/F/M/?（**取代 03 文档的 N/P**） | — | 返回键两级语义：先 OSD→再退出+二次确认（默认焦点「取消」） |
| 面板 | 控制栏+右键菜单（每项控制栏同样可达） | 底部弹层 | OSD 二级菜单 |
| 选项顺序 | 清晰度：**自动/流畅/标清/高清/超清/蓝光**；倍速 0.5×–2.0×；字幕「关闭字幕」；音轨 | 同左（逐字一致） | 同左 |
| 异常态 | 起播 1s/5s 分级提示+取消；缓冲保留末帧；清晰度切换保留当前帧；失败=三段式文案+重试+换线路/降清晰度；自动连播 10s 倒计时可取消 | 同左 | 同左 + 首帧<1.5s/seek<300ms/OSD<100ms/4K 硬解 |
| 专项 | 进度条悬停关键帧（必须）、画中画、多窗口 | 投屏/画中画/后台音频一级入口 | 字幕 ≥32px+半透明背景板、OSD 不遮字幕 |

### 4.5 搜索（聚合搜索为星映特色）
- 空态：历史+热搜（TV 必有**拼音首字母输入**+语音，历史横向轨道/热搜网格）。
- 结果：多源并发渐进加载（信号量 8、超时 8s、失败源跳过并置灰可重试）；**同片归并为「多源 N」卡**，点开即换源；「只看有资源的」筛选；无结果给替代推荐，禁止空白页。

## 5. 星映特性组件（新增设计）

| 组件 | 桌面 | 手机 | TV |
|---|---|---|---|
| **源管理** | 数据表格（排序/列宽/行悬停/右键菜单）+ 批量启停删 + 添加源/导入 TVBox 配置 | 列表行 + 底部弹层操作 | 设置内列表（行高 120px，无表单） |
| **健康度徽标** | 圆点（优良/良好/降级/不可用）+ 分值 + 延迟 + 最近检测 | 圆点 + 摘要 | 源行内文字（3 米可读） |
| **空库引导** | 添加源向导（URL/粘贴/文件/扫码） | 同左 + 扫码 | 「展示配置码 + 手机扫码填写」（TV 禁长表单） |
| **播放内核选择** | 设置页下拉 | 底部弹层 | 设置页分段选择（自动/EXO/IJK/系统） |
| **失败兜底** | 「需原生蜘蛛」源明确标记不可用原因 | 同左 | 同左（F6：置灰源不可聚焦，不设死区） |

## 6. 状态覆盖（规范 P5 + 6.4b）

五态（加载/空/错误/无权限/离线）+ 影音异常态（起播/缓冲/切清晰度/降清晰度提示/播放失败/播完引导）在三端逐屏标注（手机画板 S+ 区有可视化样例）；空状态三问（缺什么/为何重要/下一步）与三段式错误文案贯穿；删除类操作可撤销优先（Snackbar 撤销）。
