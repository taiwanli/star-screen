0为什么要 2.0

v1 解决了「能播、三端一致、源引擎可用」，但交互反馈层几乎空白： 选集看不出选中、按下去没有确认感、全局无动效语言、无音效/触感。 这不是小修，而是感知质量的系统升级 —— 苹果把这套叫 Delight / Feedback / State。

用户原话：「鼠标选集的时候要有反应，当前情况选到哪一集都不清楚， 可以使用 iOS 系统选择软件导航栏时的反馈方式」—— 这是 2.0 的第一优先级。

v1 自我反思

层v1 问题根因
状态可见性选集/筛选/内核选中态弱或无只做了功能态，没做「选中态 + 过渡态」
操作反馈点击无缩放/波纹弱、无声音未建立全局动效/音效规范
空间引导列表/详情/播放切换生硬缺共享元素、缺弹性曲线
错误反馈仅 SnackBar 文本无图标动效、无可执行动作入口
一致性桌面 Hover、TV 焦点、手机 Touch 三套半成品无统一 Interaction Token

1苹果系统交互调研（HIG / iOS / macOS）

1.1 选择反馈（Segmented / Tab / Picker）

模式苹果做法可迁移到星映
Segmented Control 滑动指示条（spring）、文字从 55%→100% 透明度、选中底填充 分类 Chip、线路 Tab、播放引擎单选
Tab Bar 图标弹性放大、色变、可选 UISelectionFeedbackGenerator 左侧导航、TV 焦点、底部条
Picker / Wheel 滚动停靠刻度 + 轻触感 tick 选集横滑、倍速、音量

1.2 动效曲线（必须锁 Token）

  • Spring：response 0.25–0.45s，damping 0.8–0.9（iOS 17 spring(duration:bounce:)）
  • Ease-out 出场 / ease-in 入场；转场 300–350ms
  • 缩放：Hover/选中 1.03–1.06，按下 0.94–0.97，TV 焦点 1.03
  • 位移：Hover 上浮 2–4px + 阴影加深 20–30%
  • 共享元素（SwiftUI matchedGeometry）：海报 → 详情小海报

1.3 音效 / 触感（iOS 精神，桌面用音效代替 Taptic）

场景iOS星映 2.0 桌面星映 2.0 触屏
选中刻度UISelectionFeedback light极轻 tick 音（可关）触感 selection
按钮确认impact(.light/.rigid)click 轻响 + 缩放impact light
成功/完成通知型触感短促上升音success 触感
错误警告型低频短音 + 图标抖动warning 触感

全屏/沉浸视图折叠动画无音，纯动效同左
苹果原则：音效只用于「状态改变的确认」，不要用在持续动画上；触感/音效必须可在设置里关掉。

1.4 其它值得抄

  • Long Press → Context Menu（iOS）：选集长按出「播放/收藏/标记已看」
  • Pull to Refresh：分类页下拉刷新
  • Live Activities / 状态胶囊：播放中角标「第 N 集」
  • Haptics on scroll：分页边界轻 tick
  • Reduce Motion：尊重系统「减弱动态效果」，降级为淡入淡出

  • 选中态唯一：当前播放集 > 上次观看集 > 悬停态（优先级）

42.0 交互设计原则（锁死）

原则

  • 可感知：任何状态变化必须有视觉/触感/音效之一
  • 短：反馈 < 300ms，禁止阻塞操作
  • 一致：同一动作三端同一套 token
  • 可关：音效/动效在设置可降级（含系统 Reduce Motion）
  • 不抢戏：视频区动效克制，列表/详情可更活泼

Interaction Tokens

scale.hover1.03
scale.press0.96
scale.focus (TV)1.03
duration.micro120–180ms
duration.base250–350ms
spring0.35s / bounce 0.15
easingcubic-bezier(.2,.8,.2,1)

52.0 实施分期

阶段内容产出
M1
反馈底座		 Interaction Tokens；选集/Chip/按钮三态；音效与触感引擎（可关）；Reduce Motion 选集「一眼知道选哪集」
M2
流转动效		 导航转场、详情入场、播放全屏、收藏 pop、错误抖动、下一集横幅 全站有「运动语言」
M3
质感与声音		 骨架屏、count-up、共享元素、拖拽排序、TV 光晕、完整音效包 接近 iOS 的「爽感」

6验收标准

  • 选集：3 秒内任意用户能说出「当前第几集 / 上次看到哪」
  • 所有可点元素：Hover / Press / Selected 三态齐全
  • 动效总时长可感知但不拖沓；开启「减弱动效」后无缩放弹跳
  • 音效默认轻、可关；播放中不叠加持续噪音
  • 三端同一 Token；TV 以焦点态替代 Hover
